Scripts in the loop

Pages with MiniScript, served by Fourfold M2. Each request runs in a fresh VM.

  • Hello: render fills a page's fields, using a module from lib/.
  • Contact: a form posted to a post handler, which redirects.
  • api/echo: a get handler returning JSON.
  • Slow: waits a second without holding up anyone else.
  • Oops: a runtime error, shown with its file and line (in dev mode).
  • Forever: an endless loop, stopped by the instruction budget.
